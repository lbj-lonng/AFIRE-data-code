Data availability

The source data underlying Figs. 1–4 and Supplementary Figs. S1–S10, including all 135 stored health-analysis estimates for the five reported outcomes, exposure summaries for 2009–2020 and matched validation records, are publicly available at https://github.com/lbj-lonng/AFIRE-data-code/tree/ab380fca168a4e2cc025cbad31fb10db7da8903b/data. Variable definitions and provenance are provided in the repository. Original data sources and access routes are documented in the Supplementary Information and repository bibliography. Suppressed mortality cells remain missing. Individual allocation arrays and reconstructed suppressed county-level death counts are not redistributed; the shared files support inspection and replotting of reported results but do not include all inputs needed to refit the mortality models.

Code availability

Custom analysis and figure-reproduction code is available at https://github.com/lbj-lonng/AFIRE-data-code/tree/ab380fca168a4e2cc025cbad31fb10db7da8903b. The repository includes the original implementations, subsequent B1 joint-adjustment and seven-outcome extensions, and scripts to reconstruct all four main and ten supplementary figures from frozen Source Data. Dependencies, reproduction instructions and verification checks are provided. Historical model-fitting scripts are archived; end-to-end refitting from the publicly shared files has not been validated.
