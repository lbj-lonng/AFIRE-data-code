Data availability

The numerical data underlying Figs. 1–4 and Supplementary Figs. S1–S10 are provided in the accompanying Source Data package, together with all 135 stored health-analysis estimates for the five reported outcomes, exposure summaries for 2009–2020 and matched validation records. Variable definitions, provenance and original data-source links are included in the package. Mortality and population data were obtained from CDC WONDER (https://wonder.cdc.gov/), subject to its data-use restrictions (https://wonder.cdc.gov/datause.html); socioeconomic, environmental, wildfire and geographic sources are documented in the Supplementary Information and the supplied source bibliography. Suppressed mortality cells remain missing in the shared records. Individual allocation arrays and reconstructed suppressed county-level death counts are not included in the public package; these are model-generated plausible values, not observed hidden counts. The shared files support inspection and replotting of the reported results but do not constitute a complete dataset for refitting all models.

Code availability

The accompanying Supplementary Code package contains the original analysis implementations, the subsequent B1 joint-adjustment and seven-outcome extension code, and scripts for reconstructing Figs. 1–4 and Supplementary Figs. S1–S10 from frozen Source Data. The release includes a portable figure-reproduction entry point, dependency requirements, a data-verification script and file checksums. All four main figures and ten supplementary figures were successfully regenerated during release verification without refitting mortality models or regenerating allocations. The historical model-fitting scripts retain their original configurations and dependencies; unrestricted end-to-end refitting from the public package has not been validated. Reproduction instructions and remaining upstream provenance and environment gaps are documented in the package.
