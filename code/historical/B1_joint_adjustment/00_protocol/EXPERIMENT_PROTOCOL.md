## 模型与推断

主要计数模型沿用原协议：县—年死亡计数为因变量，log(人口)为offset；negative-binomial GLM（原注册为PPML的O03例外）并使用县聚类稳健标准误；县固定效应和相应年份固定效应；每份插补分别拟合；log系数与方差先按Rubin规则合并，再用 `100×[exp(beta)-1]` 转换。

效应解释固定为：每1个烟霾IQR、每1 SD基线社会经济劣势的死亡率比之比的百分比变化。固定baseline SES主效应被县固定效应吸收，不强行重复加入。

共同样本模型公式已在 `config.json` 冻结。关键结构为：M2P从M2增加降水；M3从M2增加非野火PM2.5和臭氧，M3本身不含降水；M3L从M3增加昼间LST。本轮唯一新增模型为：

- `M3P_joint = M3 + precipitation`
- `M3PL_joint = M3 + precipitation + daytime LST`

这两个模型是本轮提出的补充稳健性分析，不伪称最初预设，也不自动取代原O10参考模型。
